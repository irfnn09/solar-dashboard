# 🌌 Solar System Dashboard

A real-time astronomy dashboard powered by NASA API.

## Features
- 📸 NASA Astronomy Picture of the Day (APOD)
- 🪐 Information about all 8 planets
- 🌙 Dark space-themed UI

## Tech Stack
- Python
- Flask
- NASA API
- HTML/CSS

## Setup
1. Clone this repository
2. Install dependencies: `pip install -r requirements.txt`
3. Add your NASA API key in `.env` file
4. Run: `python app.py`
